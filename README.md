# Нейросводка — бесплатная лента новостей об ИИ

Каждый час GitHub сам собирает новости из проверенных источников, пересказывает их по-русски простым языком и обновляет сайт. Лимиты Claude не тратятся: пересказ делает бесплатная модель GitHub Models, а запуски идут в бесплатных GitHub Actions.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Сам сайт |
| `feeds.json` | Список источников (можно редактировать) |
| `scripts/update.py` | Сборщик: читает ленты, отбирает новости про ИИ, отправляет на пересказ |
| `.github/workflows/update.yml` | Расписание: запуск каждый час |
| `data/news.json` | Лента новостей (обновляется автоматически) |

## Установка (10 минут, один раз)

1. **Создайте аккаунт на GitHub**, если его нет: github.com → Sign up.
2. **Создайте репозиторий**: кнопка «+» вверху → New repository → имя, например `ai-news` → **Public** → Create repository.
   Публичный нужен для бесплатного GitHub Pages. Если хотите приватный, Pages для него требует платного плана.
3. **Загрузите файлы**: на странице репозитория → «uploading an existing file» → перетащите **содержимое** распакованного архива (папки `.github`, `data`, `scripts` и файлы `index.html`, `feeds.json`, `README.md`) → Commit changes.
   Папка `.github` скрытая: если она не видна, включите показ скрытых файлов (macOS: Cmd+Shift+. в Finder; Windows: Вид → Скрытые элементы).
4. **Разрешите сохранять обновления**: Settings → Actions → General → внизу «Workflow permissions» → **Read and write permissions** → Save.
5. **Включите сайт**: Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save. Через 1–2 минуты появится адрес вида `https://ВАШ-ЛОГИН.github.io/ai-news/`.
6. **Первый запуск вручную**: вкладка Actions → слева «Обновить ленту» → Run workflow → Run workflow. Через 1–3 минуты на сайте появятся новости.

Дальше всё работает само каждый час.

## Как это проверяет новости

- Берутся только источники из `feeds.json`: официальные блоги компаний и лабораторий (OpenAI, Google DeepMind, Google AI, Microsoft Research, NVIDIA, Hugging Face) и крупные издания (The Verge, Ars Technica, TechCrunch, MIT Technology Review, Wired, Help Net Security, BleepingComputer), плюс блог Саймона Уиллисона.
- Модель пересказывает **только** заголовок и анонс из источника и не добавляет фактов от себя.
- Новости из блогов компаний помечены «Блог компании»: это то, что компания говорит о себе.
- Под каждой новостью есть ссылка на оригинал.
- Если какой-то источник сменил адрес ленты, сайт покажет его в списке «Сейчас недоступны». Исправьте адрес в `feeds.json`.

## Если пересказа нет и новости на английском

Бесплатный лимит GitHub Models — примерно 150 запросов в сутки на аккаунт, а сборщик тратит не больше 3 запросов в час (до 72 в сутки). Если лимит исчерпан или модель недоступна, новость появится на английском, а пересказ добавится при следующем запуске.

Если GitHub уберёт модель, откройте `.github/workflows/update.yml` и добавьте в шаг «Собрать и пересказать новости» строку `MODELS: openai/gpt-4o-mini` (или другую модель из каталога github.com/marketplace/models) рядом с `GITHUB_TOKEN`.

## Изменить расписание

В `.github/workflows/update.yml` строка `cron: "17 * * * *"` означает каждый час. Каждые 3 часа: `"17 */3 * * *"`. Время указывается по UTC.
